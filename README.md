# beanhop.com

Website for Bean Hop Consulting, LLC (Ashley Schultz). Plain HTML and CSS, hosted on GitHub Pages.

- `index.html`: home page
- `blogs/industry-insights/`: articles, at the same addresses they had on Shopify
- `images/`: site images; `images/blog/` is filled by the "Copy blog images from Shopify" workflow
- `_tools/`: build script and source data (not published)
